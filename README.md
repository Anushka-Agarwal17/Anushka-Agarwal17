## Engineering Approach

I believe good software engineering starts with understanding the problem, not immediately writing code.

- **Problem First:** Understand the actual problem, constraints, and expected outcome before choosing an implementation.
- **Ownership:** Take responsibility for understanding, developing, debugging, and improving a solution.
- **AI-Driven Development:** Use AI tools to accelerate research, explore designs, generate code, and assist with testing.
- **Critical Thinking:** Validate AI-generated suggestions, question assumptions, and make independent technical decisions.
- **Practical Implementation:** Focus on building working applications rather than limiting ideas to theoretical concepts.
- **Continuous Learning:** Adapt to new technologies and learn unfamiliar tools when a problem demands them.
